# 网约车客诉处理规范

本规范适用于平台客服处理网约车类客户投诉。目标是统一补偿标准，提升客户满意度。

## 司机迟到处理

司机未按预约时间到达上车点，视为迟到。

### 补偿标准

司机迟到5分钟以内，客服致歉安抚即可，无需经济补偿。

司机迟到5到15分钟，致歉后发放10元打车优惠券，24小时内到账。

司机迟到15到30分钟，致歉后发放20元打车优惠券，同时为客户优先匹配附近车辆。

司机迟到超过30分钟，免除本次订单费用，发放50元打车优惠券，并将问题升级至主管跟进。

### 处理步骤

1. 确认订单信息：通过订单号查询行程详情、预定时间和实际到达时间
2. 联系司机：通过平台电话联系司机，确认当前位置和预计到达时间
3. 安抚客户：告知客户已联系司机，根据迟到时长告知补偿方案
4. 执行补偿：根据补偿标准发放优惠券或免单
5. 记录归档：在工单系统记录处理过程和结果

## 司机未到达处理

司机接单后未前往上车点或无法联系的情况。

### 补偿标准

等待时间在5分钟以内且无法联系司机，取消订单全额退款。

等待时间在5到15分钟，全额退款并补偿10元打车优惠券。

等待时间超过15分钟，全额退款并补偿20元打车优惠券，同时为客户优先派单。

### 处理步骤

1. 确认司机状态：查询司机实时位置和联系方式
2. 尝试联系司机：通过平台电话联系司机
3. 帮客户重新叫车：取消当前订单，使用优先派单为客户重新下单
4. 执行退款和补偿：根据补偿标准处理退款和发放优惠券
5. 记录归档：在工单系统记录处理过程和结果

## 费用争议处理

客户对行程费用产生疑问时的处理流程。

### 处理步骤

1. 查询订单明细：获取行程距离、时长、费用构成
2. 核实计费规则：确认是否符合平台计价标准
3. 如有异常：退还多收费用，发放10元优惠券致歉
4. 如无异常：向客户解释费用构成，展示计价明细
