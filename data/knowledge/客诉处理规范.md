# 客诉处理规范

## 总则
本规范适用于旅游平台客服团队处理各类客户投诉。目标是在保障客户满意度的同时，维护公司利益。

## 客诉分类
### 按品类分类
- 机票类：退票、改签、退差价、行李、延误
- 酒店类：取消预订、房间问题、预订确认、发票
- 火车类：退票、改签、误车、座位问题
- 打车类：司机迟到、司机未到、费用争议、安全问题

### 按严重程度分类
- P1（紧急）：涉及金额超过1000元、12315投诉威胁、负面舆情风险
- P2（一般）：普通投诉，涉及金额100-1000元
- P3（轻微）：咨询类、建议类、小型不便

## 处理原则
1. 先道歉，再解决：任何客诉首先表达歉意，再进入问题解决
2. 能快不快：简单问题5分钟内给出解决方案
3. 升级机制：一线客服无法解决的问题，5分钟内升级主管
4. 闭环追踪：每单客诉需记录处理结果并回访

## 补偿标准参考
### 机票类
- 因平台原因导致订单问题：退还服务费 + 50元优惠券
- 因航司原因导致延误：按航司标准协助理赔

### 酒店类
- 房间卫生问题：退还当日房费 + 等额优惠券
- 无法入住：全额退款 + 补偿同城同档次酒店差价

### 打车类
- 司机迟到5-15分钟：致歉 + 10元优惠券
- 司机迟到15-30分钟：20元优惠券 + 优先派单
- 司机迟到30分钟以上：免单 + 50元优惠券 + 升级主管
- 司机未按时到达：全额退款 + 20元优惠券

### 火车类
- 车票问题导致无法出行：全额退款 + 协助购买替代车票
